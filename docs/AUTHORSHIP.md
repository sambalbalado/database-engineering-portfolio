# Authorship and material boundaries

Esaam Matudin completed the two original educational case studies. They represent practice in database design and implementation, rather than paid client work or production deployments.

| Material | Attribution |
| --- | --- |
| Waste conceptual model, normalisation, assumptions, logical and relational model | Original author work, cleaned for portfolio presentation. The SQL baseline was generated from that model by Oracle SQL Developer Data Modeler 24.3.1. |
| Transport business model and reference-table design | Supplied exercise design. The portfolio does not claim original authorship of that model. The supplied diagram and original starter code are not redistributed. |
| Transport core schema, booking lifecycle, migrations, reports, SQL/JSON and MongoDB operations | Curated from the author's completed implementation. Template declarations, grading controls and repeated question instructions were removed. |
| Original transport sample data | The source explicitly acknowledged **Google Gemini** assistance to generate employee, quote and job insert statements. The prompt specified record coverage, explicit date formats, roles, relationships and cost cases. This acknowledgement is retained here; the classroom prompt text is omitted. |
| Portfolio support and review | **OpenAI Codex** assisted with review, documentation, genuine PDF redaction, model metadata cleanup, integrity overlays, missing reference-table DDL, fresh synthetic reference fixtures, current-schema diagrams, runtime assertion scripts and static checks. |

Original SQL structure is retained where sound. Substantive modifications are listed in [CORRECTIONS.md](CORRECTIONS.md). Original files and a private source inventory remain outside the repository. The commit history represents portfolio preparation now, not the original development chronology.

All included records are synthetic demonstrations. Added customer names use Demo labels, addresses use Example Avenue, email uses `example.invalid`, and contact numbers begin with `000`. Named actors retained in the booking scenario are fictional exercise records. Vehicle identifiers are demonstration strings; no registration or manufacturer authenticity is claimed.

The original specifications, teaching examples, marking material, feedback, annotated diagrams and starter scripts are excluded. The new reference-table implementation replaces an unavailable dependency for reproducibility; that replacement does not establish publication rights for other material. Publication permission and the right to grant a software licence are separate decisions. There is no blanket open-source licence.
